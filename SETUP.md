# Publish your GitHub profile

1. Sign in to GitHub as `techwings0710` (if this is still your username).
2. Create a **public** repository named **`techwings0710`** exactly.
3. Upload `README.md` to the repository root.
4. Upload `assets/banner.svg` inside an `assets` folder, maintaining that same path.
5. Commit the files. Visit `https://github.com/techwings0710` to see your new profile README.
6. Edit the text or add your Heritage Shield link when ready.

The banner is locally stored and does not depend on an image host. The two activity widgets are powered by a third-party service and may occasionally fail to render or be rate-limited. Remove them if you prefer no external dependencies.

Avoid adding claims, language badges, or project technologies you cannot explain in an interview.
